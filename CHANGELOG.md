# Changelog

This project uses semantic versions: `vMAJOR.MINOR.PATCH`.
Pushing a tag such as `v1.0.0` runs the Release workflow and publishes GitHub release notes from the commits since the previous tag.

## 1.0.0

- Add the Express API for accounts, trips, experiences, and messages.
- Add the React client for browsing trips, profiles, stories, and chat.
- Add request logs, database call logs, input checks, and automated tests.
