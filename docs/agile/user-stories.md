# User stories

Each story is one small piece of Solo Trip. The board below is the project Kanban.

## Board

### Done

- As a new member, I want to register with my name, city, and travel style, so other women know who I am.
- As a member, I want to log in with my email and password, so I can publish trips and send messages.
- As a visitor, I want to browse trip listings, so I can find a companion whose dates overlap mine.
- As a member, I want to publish a trip with dates, budget, and a short plan, so the right companion can find me.
- As a member, I want to read and share travel experiences, so the community can pass on safety and budget advice.
- As a member, I want to message the host of a trip, so we can compare dates in private.

### In progress

- As a reviewer, I want three separate pull requests with review comments, so large changes are checked before they reach `main`.

### To do

- As a maintainer, I want a `v1.0.0` git tag and a GitHub Release, so the course CI/CD checklist has a published version.
